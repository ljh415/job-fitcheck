# 전체 앱 회귀 테스트 체크리스트

`feat/rag-integration-plan` → `main` merge 직후 회귀 확인용. anthropic/openai/google-genai/
httpx/pydantic 등 여러 기능이 공유하는 라이브러리 버전이 이번 merge로 함께 올라가서, RAG를
안 쓰는 사용자에게도 영향 범위가 있다. 우선순위(P0/P1/P2) 순서로 실행 — P0가 깨지면 뒤는
진행하지 않는다. RAG 자체 기능 검증은 [rag_testing_checklist.md](rag_testing_checklist.md)
참고(여기서는 링크만, 중복 작성 안 함).

## P0 — 빌드·기동·인증 (실패 시 진행 중단)

### 0. 빌드·기동·라우팅

- [ ] `docker compose up --build -d` → API/nginx 정상 기동
- [ ] `GET /api/health` 정상 응답
- [ ] 정적 파일(SPA) 정상 로딩
- [ ] `RAG_POSTGRES_HOST` 미설정 상태 → `/api/rag/status` 외 RAG 엔드포인트 503, 나머지
      기능 정상
- [ ] SPA 직접 URL 진입, 새로고침, 브라우저 뒤로가기 정상 동작
- [ ] uv 직접 실행 경로(`python3 backend/main.py`)로도 기존 기능 정상

### 1. 인증

- [ ] 올바른 `APP_SECRET`으로 로그인 성공
- [ ] 잘못된 비밀번호 → 401
- [ ] 토큰 없이 보호된 API 호출 → 401
- [ ] 컨테이너 재시작 후에도 기존 세션 정상 동작

## P1 — 핵심 기능 회귀 (라이브러리 버전 변경 영향권)

### 2. 회사 등록·분석

- [ ] URL 입력으로 등록 → 스크래핑(`httpx`) + LLM 분석 정상
- [ ] 텍스트 붙여넣기로 등록 → 구조화 추출 정상
- [ ] 이미지 업로드로 등록 → OCR/분석 파이프라인 정상
- [ ] Wanted 동기화 정상
- [ ] Jobplanet 검색 연동 정상
- [ ] refill(재분석) 정상
- [ ] provider 3종(Claude/OpenAI/Gemini) 중 키가 있는 것 각각 최소 1회 위 동작 확인 —
      provider마다 전체 항목을 반복할 필요는 없고, 전환 후 등록/재분석 1회로 구조화·생성·
      평가 경로를 함께 검증

### 3. 프로필·적합도 평가

- [ ] 프로필 PDF 업로드 → 파싱 정상
- [ ] 프로필 수동 편집 저장 정상
- [ ] 프로필 있는 상태에서 적합도 평가 정상
- [ ] 프로필 없는 상태에서 적합도 평가 시 안내 정상(에러 아님)
- [ ] 프로필 재업로드 후 갱신된 내용 기준으로 평가 반영 확인

### 4. 기존 Q&A (SSE 스트리밍)

- [ ] 질문 전송 → 스트림 시작·완료 정상
- [ ] 스트리밍 도중 취소 정상
- [ ] 대화 기록 저장·조회 정상
- [ ] provider 3종 중 키가 있는 것 각각 최소 1회 확인

### 5. 설정

- [ ] provider 전환 정상 반영
- [ ] 모델 목록 조회 정상
- [ ] 모델 수동 override 저장 정상
- [ ] `reasoning_effort`(gpt-5 계열) 설정 반영 확인
- [ ] 알림 설정 저장 정상
- [ ] 주간 요약 스케줄 설정 저장 정상
- [ ] 컨테이너 재시작 후 위 설정들이 `runtime_settings.json`에서 복원됨

### 6. 알림

- [ ] 텔레그램 테스트 메시지 발송 정상(키 있는 경우)
- [ ] 슬랙 테스트 메시지 발송 정상(키 있는 경우)
- [ ] 디스코드 테스트 메시지 발송 정상(키 있는 경우)
- [ ] 자격증명 없는 채널은 "미실행"으로 명시하고 스킵

### 7. RAG 비활성 상태에서 CRUD 훅 부작용 없음

이번 merge로 회사·프로필 CRUD 경로에 RAG 재색인 훅이 새로 추가됐다 — RAG를 안 쓰는
사용자에게 이 훅이 조용히 실패하거나 지연을 유발하지 않는지가 핵심.

- [ ] 회사 등록/편집/refit/Wanted 동기화/삭제 각각 실행 → 정상 동작, 응답 지연 없음
- [ ] 프로필 편집·업로드 → 정상 동작
- [ ] API/컨테이너 로그에 Postgres 연결 시도나 관련 오류 없음

## P2 — UI·관리 기능·RAG

### 8. 회사 관리 SPA

`frontend/app.js`에 RAG 관련 코드가 다수 추가되고 공용 라우팅·초기화 흐름도 같이
수정됐으므로, RAG 화면만이 아니라 기존 SPA 전반을 확인한다.

- [ ] 회사 목록·상세 조회 정상
- [ ] 검색·필터·정렬 정상
- [ ] 핀 고정/해제 정상
- [ ] 비교 화면 정상
- [ ] 타임라인 정상
- [ ] `/rag` 화면 방문 후 기존 화면(목록/상세 등)으로 돌아왔을 때 상태 이상 없음
- [ ] 모바일 화면 폭에서 주요 버튼 정상 노출·동작

### 9. 백업·내보내기

- [ ] ZIP 내보내기 → 압축 정상, `.md`/`.raw.txt`/프로필/평가 기준 포함 확인
- [ ] CSV 내보내기 정상
- [ ] 프로필 export 정상
- [ ] 회사 삭제 시 `data/backup/`에 자동 백업 생성 확인(최근 5개 유지)
- [ ] RAG Postgres 데이터는 export에 없어도 정상(원본 아닌 파생 색인이므로 재생성 가능)
